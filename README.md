# Python Car Dealership

A console-based car dealership inventory management system developed in
Python. The program allows users to view, add, and remove vehicles while
validating user input.

## Features

- View vehicle information including make, year, and price
- Add new vehicles to the dealership inventory
- Remove vehicles from the inventory
- Display all available vehicles
- Validate menu selections and vehicle information
- Handle invalid user input using exception handling
- Automatically update valid selection ranges as inventory changes

## Running the Project

Run `get_car_info.py` to start the program.

The program displays a menu that allows the user to manage the dealership
inventory through the console.
